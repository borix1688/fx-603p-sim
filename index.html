使用者程式庫（存 / 載 / 匯入 / 匯出）

自動儲存：任何程式／記憶體變更都會立即寫入 localStorage（瀏覽器關閉後仍在）。程式庫是具名快照，可反覆載入。換電腦請用「匯出備份 JSON」。

程式區塊

要執行程式：先確認在 MODE 0 (RUN)，然後直接點下面的區塊編號（P10–P19 只能用這裡點）；鍵盤做法是按 P 再按 0–9，按完立刻執行。
要看某個區塊裡有什麼程式：切到 MODE 2 (EDIT) 或 MODE 1 (WRT) 再點該區塊（只切換檢視，不會執行），下方清單就會顯示內容。
首次開啟時 20 個區塊都是空的——內建範例要按上面的範例按鈕才會載入。

範例程式（一鍵載入）

一元二次方程式 (P1)：載入後切到 MODE 0 → 按 P → 1 → 依序輸入 A、B、C（每項按 EXE）→ 顯示 two real roots（按 EXE 續看 x1、x2）或 no real root。A=0 會顯示 not quadratic。

其他範例：載入後切到 MODE 0 (RUN) → 輸入數字 → 按 P 再按區塊編號（例如 P0）即可執行。程式內用 HLT 等輸入，按 EXE 繼續。

操作速查

模式

  • MODE 0 = RUN：計算與執行程式（輸入數字後按 P+區塊編號）。
  • MODE 1 = WRT：錄製程式；之後每個按鍵都會變成一步存進目前區塊。
  • MODE 2 = EDIT：選擇程式區塊（也可在任何模式用面板上的 P0–P19 按鈕）。

程式常用

  • STO n／RCL n：存／取記憶體 M00–M109（按 STO 後輸入 1–3 位數字）。
  • LBL n／GOTO n／GSB n／RTN：區域標籤 0–9 與副程式。
  • DSZ r：M(r) 減 1，若為 0 就跳過下一步——慣用法是後面接 GOTO n 形成迴圈；省略 r 時預設 M00（對應原廠手冊的階乘範例寫法）。
  • ISZ r：加 1，若為 0 則跳過下一步。
  • IND：下一個記憶體／跳躍步驟改用「間接」定址（M(r) 的內容當位址）。
  • HLT：暫停等輸入，按 EXE 繼續。
  • 條件測試（2nd + 鍵）：x<0（(）、x≥0（)）、x=0（π）、x≠0（%）。語意與 DSZ 相同：條件成立就跳過下一步，所以慣用法是「測試 → GOTO n」＝ 條件成立時不跳、不成立時跳到 LBL n。
  • CLS（2nd + CLR）：清除第一行文字；在 RUN 模式下直接清掉目前的第一行。
  • ALPHA：輸入文字（鍵面右上角小字就是 ALPHA 字元），會顯示在第一行。
  • =：完成運算；程式跑到區塊結尾會自動停止。

2nd / INV 第二功能

  • INV + sin/cos/tan = 反三角；INV + log/ln = 10^x／e^x。
  • 2nd + 7/8/9 = DEG／RAD／GRA；2nd + . = FIX（小數位循環）；2nd + EXP = SCI；2nd + x²=ABS、√=INT、1/x=FRAC、n!=RND。

本機沒有接實體鍵盤：所有輸入都用畫面上的按鍵（避免與面板輸入框衝突）。

實作說明與已知差異

  • 核心忠實：keystroke 錄製與合併（數字字面值／STO+位址／LBL+編號各算一步）、P0–P19、LBL0–L9、DSZ 跳過下一步的語意、HLT+EXE 續跑、IND 間接定址、ALPHA 文字輸出到第一行——都依 FX-603P 公開資料的程式模型實作。
  • 鍵位與 ALPHA 對應是重建：我沒有逐鍵對照的原廠手冊圖，鍵盤排列與「哪個鍵在 ALPHA 下打出哪個字元」是照功能合理配置，鍵面右上角小字即實際對應。
  • MODE 只實作 0/1/2（RUN／WRT／程式區選擇）；統計、BASE-N、複數、積分等模式未實作。
  • 條件測試（x<0 / x≥0 / x=0 / x≠0）與 CLS 是我補的：實機確實有條件跳躍指令，但我查不到可逐鍵對照的鍵位與助憶符，因此設計成 2nd 層、語意沿用 Casio 的「成立就跳過下一步」。
  • 顯示：主顯示 2 行 × 16 字元 5×7 點矩陣、右側 4 位步數顯示、20 格狀態指示——皆為點矩陣重繪；步數顯示實機是 7 段式，這裡沿用點矩陣。
  • 精度：內部用 JS double，顯示端做 12 位有效數字與 ±99 指數格式化（實機為 12 位尾數）。
  • 儲存：程式與記憶體存在 localStorage（同一瀏覽器／同一網域）；跨裝置請用 JSON 匯出／匯入。無痕模式或清除網站資料會一併清掉。
