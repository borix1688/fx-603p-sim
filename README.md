# CASIO FX-603P 模擬器（Keystroke Programmable）

> 🌐 線上部屬（啟用 GitHub Pages 後）：<https://borix1688.github.io/fx-603p-sim/>

單檔、離線可跑。雙擊 `index.html` 即可，不需要伺服器、不需要網路。

**重點：這是可程式電卓 —— 你可以自己錄程式，而且寫好的程式會存在瀏覽器裡，關掉瀏覽器再開還在。**

## 這是什麼機器

1990 年 Casio 推出的可程式電卓旗艦 **FX-603P**，是 1981 年傳奇機 **FX-602P** 的後繼機，只在少數國家少量販售，如今極罕見。規格（依 Wikipedia）：

| 項目 | 規格 |
| --- | --- |
| 顯示 | 2 行 × 16 字元 dot-matrix LCD + 4 位數步數／指數顯示 + 20 個狀態指示 |
| 程式記憶 | **6,144 步**（keystroke，fully merged） |
| 資料暫存器 | **110 個** |
| 程式標籤 | **P0–P19**（前代的 2 倍），每個程式另有 **LBL0–LBL9** |
| 定址 | 支援**間接定址**（記憶體與跳躍）→ 具 Turing complete 能力 |
| 相容 | 可載入 FX-602P 的程式（原機從卡帶） |
| 介面 | FA-6（Kansas City 卡帶 / Centronics / RS-232） |

## 功能

**計算**：四則與優先權、括號與隱含乘法、√、x²、x^y、1/x、n!、log/ln、10^x/e^x、sin/cos/tan 與反三角、π、%、EXP、DEG/RAD/GRA、FIX/SCI、STO/RCL/M+/M−（M00–M109）、IND 間接存取。

**程式（keystroke 錄製）**：`MODE 1` 之後每一個按鍵都變成一步，數字／位址會自動合併：
- 數字字面值（`1` `2` → 一步 `NUM 12`）
- `STO`/`RCL`/`M+`/`M−` + 位址（一步）
- `LBL`/`GOTO`/`GSB` + 編號（一步）
- `P` + 編號 = 切換區塊（WRT）或呼叫執行（RUN）
- `IND` 修飾下一個記憶體／跳躍步

**執行**：`MODE 0` 後輸入數字再按 `P`+區塊編號即可跑；程式呼叫另一個區塊、`GSB`/`RTN` 副程式、`DSZ`/`ISZ` 迴圈、`HLT` 暫停等輸入後按 `EXE` 續跑、`ALPHA` 文字輸出到第一行。

**範例**（面板一鍵載入）：
- `P0` 階乘 `n!`（原廠手冊經典範例的 DSZ + GOTO 寫法）
- `P1` 圓面積（HLT → x² → ×π）
- `P2` 1..n 加總（雙迴圈計數）

## 程式保存（你要的那件事）

| 機制 | 說明 |
| --- | --- |
| **自動儲存** | 任何程式／記憶體變更都會寫入 `localStorage`（250ms 去抖），**關閉瀏覽器再開會自動載回**；狀態列顯示最近儲存時間 |
| **具名程式庫** | 面板可把「目前全部程式 + 記憶體」存成一個具名快照，隨時載入／匯出／刪除（同名會覆蓋） |
| **匯出備份 (JSON)** | 下載完整狀態，可帶到另一台電腦／瀏覽器 |
| **程式清單 (TXT)** | 匯出可讀的程式列表與記憶體內容，方便貼文分享 |
| **匯入 JSON** | 讀回備份檔（相容「純狀態」與「程式庫項目」兩種格式） |

⚠️ 儲存是**同一瀏覽器、同一網域**的 `localStorage`：無痕模式、清除網站資料、換裝置都會失去，跨裝置請用 JSON 匯出／匯入。

## 操作速查

- **模式**：`MODE 0` = RUN、`MODE 1` = WRT（錄製）、`MODE 2` = EDIT（選區塊）
- **執行**：輸入數字 → `P` → 區塊編號（例：`P0`）；面板上也有 P0–P19 按鈕
- **第二功能**：`INV`+三角 = 反三角、`INV`+log/ln = 10^x/e^x；`2nd`+`7/8/9` = DEG/RAD/GRA、`2nd`+`.` = FIX 循環、`2nd`+`EXP` = SCI、`2nd`+`x²`/`√`/`1/x`/`n!` = ABS/INT/FRAC/RND
- **ALPHA**：鍵面右上角小字就是 ALPHA 模式下打出的字元
- **DSZ 語意**：`DSZ r` 把 M(r) 減 1，**若為 0 就跳過下一步**——慣用法是後面接 `GOTO n`；省略 r 時預設 M00（對應原廠手冊範例的寫法）
- 上一行 `5 + =` 這種缺運算元的寫法會複製堆疊頂端（= 10），與 Casio 行為一致

## 實作說明與已知差異

- **忠實的部分**：keystroke 錄製與合併、P0–P19、LBL0–L9、`DSZ` 跳過下一步的語意、`HLT`+`EXE`、`IND` 間接定址、`ALPHA` 文字輸出到第一行——依 FX-603P 公開資料的程式模型實作。
- **鍵位與 ALPHA 對應是我重建的**：我沒有逐鍵對照的原廠手冊圖，鍵盤排列與「哪個鍵在 ALPHA 下打出哪個字元」是照功能合理配置；鍵面右上角小字即實際對應。
- **MODE 只實作 0/1/2**；統計、BASE-N、複數、積分等模式未實作。
- **步數顯示**實機是 7 段式，這裡沿用點矩陣繪製。
- **精度**：內部用 JS double，顯示端做 12 位有效數字與 ±99 指數格式化（實機為 12 位尾數）。
- **沒有音效**：FX-603P 實機沒有蜂鳴器，所以這台也是靜音的（不是壞掉）。
- 6,144 步上限是「數字上限」：超過會擋下並顯示 ERROR，但實機的記憶體分割行為未模擬。
